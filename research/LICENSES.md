API guidelines require hotlinking the returned image URLs, triggering the download endpoint when a photo is used, and crediting the photographer and Unsplash. The user supplies their own access key. https://unsplash.com/license · https://help.unsplash.com/en/articles/2511245-unsplash-api-guidelines |
| Pexels API | Stock photo search when online | The Pexels License allows free commercial use. API terms ask for a visible link back to Pexels and credit to the photographer where possible. The user supplies their own key. https://www.pexels.com/license/ · https://www.pexels.com/api/documentation/ |
| Anthropic Claude API | Cloud AI generation | The user supplies their own API key. Content is subject to Anthropic's usage policies. |
